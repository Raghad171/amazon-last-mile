# Amazon Last-Mile Analytics

An end-to-end data engineering and analytics project that turns last-mile delivery data into insights for operational decision-making.

The project brings together a layered data lake, data quality checks, analytical reporting, and a Power BI dashboard to explore route and station performance.

**Technologies:** Python · PySpark · Snowflake · Power BI
